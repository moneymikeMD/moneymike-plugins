# moneymike-plugins

A Claude Code plugin marketplace for Mike Garrett's plugins. Each entry points at the plugin's own repository and tracks its default branch.

```
/plugin marketplace add moneymikeMD/moneymike-plugins
```

| Plugin | Repository |
| --- | --- |
| `work-order` | [moneymikeMD/work-order](https://github.com/moneymikeMD/work-order) |
| `work-order-jira` | [moneymikeMD/work-order](https://github.com/moneymikeMD/work-order/tree/main/plugins/work-order-jira) |
| `night-watchman` | [moneymikeMD/night-watchman](https://github.com/moneymikeMD/night-watchman) |
